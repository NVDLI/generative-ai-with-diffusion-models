# Tutorial Data

Downloaded datasets live in this directory and are ignored by Git.

- FashionMNIST is downloaded automatically by torchvision.
- TensorFlow Flowers is installed under flower_photos automatically by Modules
  04 and 05, or manually by running download_flowers.py. The data is downloaded
  directly from the public TensorFlow Flowers archive.

The flowers archive includes a LICENSE.txt file with creator attribution. Keep
that file with any local or redistributed copy of the images.
